# Asia 2027 Flight & Travel Log

Interactive map and travel log built for GitHub Pages.

## Repository Files

- `index.html` — Complete application with custom interactive vector map, 2027 flight schedule, destination drawers, photo/video feed, and password-gated upload console.
- `posts.json` — Public JSON store of your travel notes, photos, and videos.
- `assets.json` — Public JSON store of custom map overlay assets anchored to destinations.
- `media/.gitkeep` — Folder where uploaded photos and videos are committed.
- `assets/.gitkeep` — Folder where custom map overlay assets are committed.

## Setup on GitHub Pages

1. Create a new GitHub repository (for example, `asia-2027`).
2. Upload all files in this package (`index.html`, `posts.json`, `assets.json`, `media/.gitkeep`, `assets/.gitkeep`, and `README.md`) to the root of your repository.
3. Open **Settings → Pages** in your GitHub repository, set **Source** to **Deploy from a branch**, select **main** and **/ (root)**, and click **Save**.
4. Open your live GitHub Pages URL, click **LOG UPDATE**, enter your password (`Lastkirby94`), and open the **GITHUB SETUP** tab.
5. Enter your GitHub username, repository name, branch (`main`), and a GitHub Personal Access Token with **Contents: Read and write** permission for this repository, then click **SAVE GITHUB SETTINGS**.

Once configured, any photo, video, note, or map asset you publish commits directly to your GitHub repository and becomes visible to everyone who visits your site.
